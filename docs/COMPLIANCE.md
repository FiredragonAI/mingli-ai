# 合规备忘

这是产品能不能上架、上架后会不会被下架的问题,优先级高于任何功能。

## 1. 定位与措辞

- 对外定位:**传统文化 · 国学 · 娱乐测试**。应用名、副标题、商店描述、内购项目名一律避免"算命、改运、化解、消灾、破解、大师"。
- 每个结果页底部固定免责声明:"内容基于传统文化整理,仅供娱乐参考,不构成任何医疗、法律、投资建议。"
- AI 提示词硬约束(见 `server/src/prompts/`):不预测疾病、死亡、灾祸;不做医疗/法律/投资建议;不鼓励付费"化解";不针对未成年人。

## 2. 应用商店

| 渠道 | 状态 | 对策 |
|---|---|---|
| Apple App Store(中国区) | 娱乐/生活分类可上,需内容分级 | 描述避免宗教迷信词汇;iOS 隐私清单声明相机用途 |
| Apple App Store(海外) | 宽松 | 主战场之一 |
| 微信小程序 | 占卜算命类目**禁止** | 不做 |
| 华为/小米/OPPO/vivo | 审核严,常以"封建迷信"驳回 | Windows 版不受影响;安卓版若做需软著 + 文化定位 |
| Microsoft Store | 宽松 | Windows 直接分发或商店均可 |

## 3. 个人信息(PIPL)

- 出生日期、地点、姓名:**个人信息**。隐私政策写明用途,本地存储,可一键删除。
- 人脸、手掌影像:**敏感个人信息**(生物识别)。
  - 首次使用前**单独弹窗告知并取得同意**(`ProfileStore.setBiometricConsent`),不与通用隐私政策捆绑。
  - 影像仅在设备内存处理,不落盘、不上传;上传的是几何比例 JSON。
  - iOS `NSCameraUsageDescription` 与 `NSPhotoLibraryUsageDescription` 写清"仅在本机分析,不上传照片"。
  - 隐私政策单列一节说明这一点。
- 后端只收匿名设备 ID 用于限流,不建账号则不收手机号/邮箱。
- 若上线大陆,后端服务器与 AI 调用的数据出境问题需评估;Claude API 在境外,应在隐私政策明示"结构化命理数据将发送至境外服务器用于生成文本",并做匿名化(不传姓名,传姓名分析结果即可)。

## 4. 内容安全

- 后端 `safety.ts` 对输入输出做关键词与主题过滤:疾病预测、寿命、自残、灾难预言、赌博投资建议一律拦截改写。
- 用户提问类功能(如后续加"问大师")需接入内容审核。
- 所有生成文本带"AI 生成"标识(《生成式人工智能服务管理暂行办法》要求)。

## 5. 支付

- 不出售"开光法物"、"改运服务"。
- 内购项目名用"详批报告"、"年度运程解读"、"起名方案"这类中性表述。
- 未成年人保护:不向未成年人推送付费。

## 6. 资质(大陆上线)

- 软件著作权(应用商店必需)。
- ICP 备案(有后端即需)。
- 若含用户生成内容或社区,需相应审核机制;v1 不含。
